# mesa-mcp documentation

This folder is the source of the mesa-mcp documentation site,
**https://idss-mesa.github.io/mesa-mcp/**. GitHub shows this file when you
browse `docs/`; the site itself starts at [`index.md`](./index.md), and
this file is not part of the built site.

mesa-mcp is an MCP server for the CyVerse Data Store (iRODS) with
ontology-driven AVU metadata (EMBL-EBI OLS), DataCite records, and a
per-project AVU history kept by mesa-ducklake.

## Pick your mode

- **Connect to an already-deployed hosted mesa-mcp** from your MCP client:
  [`user/hosted-mcp.md`](./user/hosted-mcp.md).
- **Install on your laptop** and use it with Claude Desktop, Claude Code,
  Cline or Continue: [`user/local-install.md`](./user/local-install.md).
- **Use it inside a CyVerse VICE app** (JupyterLab, RStudio Server, Cloud
  Shell): [`user/vice-apps.md`](./user/vice-apps.md).
- **Operate a hosted mesa-mcp** yourself: [`deploy/overview.md`](./deploy/overview.md).

If you are not sure, start with the local install.
